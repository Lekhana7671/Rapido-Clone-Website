# Rapido Clone Website

## About the Project

The Rapido Clone Website is a front-end web development project inspired by the Rapido ride-hailing platform. It recreates the look and layout of the Rapido website using HTML5, CSS3, and Bootstrap 5.

The website provides a clean, user-friendly interface with responsive layouts and different sections showcasing ride services, features, and app downloads.

## Features

- **Navigation Bar:** Includes Home, About Us, Safety, Careers, Blog, Press, Contact Us, and Download App links.
- **Ride Booking Section:** Provides pickup location and drop location input fields with a Book Ride button.
- **Our Services:** Displays different services such as Bike Taxi, Auto, Cab, Parcel, Travel, and Metro.
- **What We Offer:** Highlights Quick Pickup, Best Fares, and Never Too Far.
- **Earn with Rapido:** Includes a section for users interested in becoming Rapido Captains.
- **Download Section:** Displays customer and captain app download information.
- **Footer:** Includes navigation links, app store badges, and social media icons.
- **Responsive Design:** Uses Bootstrap's grid system and responsive utility classes to adapt the layout to different screen sizes.

## Technologies Used

- HTML5 – For structuring the web pages.
- CSS3 – For styling and visual presentation.
- Bootstrap 5 – For responsive layouts, navigation bar, grid system, and styling components.
- Font Awesome – For icons.
